# NINAWORLD — Y2K birthday experience

Интерактивный поздравительный сайт для Нины: React 19 + TypeScript + Vite + Framer Motion.

## Запуск

```bash
npm install
npm run dev
```

## Персонализация

- `src/content.ts`: имя, пожелания, истории и номинации.
- `public/photos/cover.jpg`: главный портрет Нины на обложке.
- `public/photos/01.jpg` ... `04.jpg`: четыре фотографии для архива. Пока файлов нет, сайт показывает оформленные цветные заглушки.
- `public/music.mp3`: опционально фоновая музыка. Включается только после нажатия на кнопку звука.

## Сборка

```bash
npm run build
```

Результат в `dist/`, можно загрузить на Vercel или Netlify.

## Функции

- Вступительный экран ENTER YOUR ERA.
- Журнальная Y2K-обложка и бесконечная бегущая строка.
- Фотоархив с модальными окнами и перелистыванием.
- SLAY DETECTOR 2000™ — шуточный тест из пяти вопросов, индивидуальные реакции на ответы, анимированный сканер и сертификат NINA CERTIFIED ICON.
- Зал славы и награды.
- Конверт с личным поздравлением.
- Конфетти, опциональный звук, адаптивная мобильная версия.
